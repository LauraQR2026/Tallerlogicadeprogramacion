# 2 Área de rectángulo

**Objetivo:** Cálculo explícito de área y perímetro desde base y altura.

 ```psc
Algoritmo AreaRectangulo
	Definir base, altura Como Real
	Definir area, perimetro Como Real
	
	Escribir "Escriba la base del rectángulo"
	Leer base
	Escribir "Escriba la altura del rectángulo"
	Leer altura
	
	area <- base * altura
	perimetro <- 2 * (base + altura)
	
	Escribir "El área del rectángulo es: ", area
	Escribir "El perímetro del rectángulo es: ", perimetro
FinAlgoritmo
 ```
