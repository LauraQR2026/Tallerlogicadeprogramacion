#Signo Numerico

 ```psc
Algoritmo SignoNumerico
	Definir Nnumero Como entero
	
	Escribir "Escriba un número"
	Leer Nnumero
	
	Si Nnumero > 0 Entonces
		Escribir "El número que escribió es positivo"
	SiNo
		Si Nnumero < 0 Entonces
			Escribir "El número que escribió es negativo"
		SiNo
			Escribir "El número que escribió es cero"
		FinSi
	FinSi
FinAlgoritmo
 ```
